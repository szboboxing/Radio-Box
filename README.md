# Radio-Box 网络收音机

纯静态、零后端的网络收音机网页。单个 HTML 文件，打开即听。

## 功能（v1.3）

- 23 台实测可用音源（音乐 / 新闻财经 / 少儿故事 / 国际 / 私人定制 / 成都）
- 播放卡：上一台 / 播放暂停 / 下一台 / 停止、音量、收藏当前台
- 可播放性检查：进页自动逐个试播，灯色 = 绿可播 / 红失败 / 灰未测，可手动重检
- 断线自动重连（最多 3 次，可开关）
- 定时关闭：15 / 30 / 45 / 60 分钟
- 搜索过滤、收藏夹（localStorage 持久化）
- MediaSession 锁屏控制、键盘快捷键（空格 / 左右方向键）
- 移动端优先响应式，暗色主题

## 使用

直接用浏览器打开 `radio.html`，或放到任意 HTTP 静态服务。

> 注意：若页面以 https 访问，浏览器会拦截 http 音源（混合内容），请用 http 或本地 file:// 打开。

## 加台

编辑 `radio.html` 顶部的 STATIONS 数组，一行一台：

```js
{n:'台名', u:'流地址', t:'mp3'|'hls', g:'分组名'}
```

- `t:'mp3'` 直连 `<audio>` 播放
- `t:'hls'` 走 hls.js（CDN 按需加载），注意跨域限制：m3u8 源必须允许你的页面来源，否则浏览器无法直连

## 音源说明

音源来自公开网络（蜻蜓 FM / BBC / StreamTheWorld），仅供学习交流。
